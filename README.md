# My-Project-
Convolutionary Neural network Challenge

## Description

The objective of this project is solve a Classification problem.The diagnosis of blood-based diseases often involves identifying and characterizing patient blood samples hence automated methods to detect and classify blood cell subtypes have important medical applications.The Algorithm employed should be able to detect and classify the blood cell into either Eosinophil or Lymphocyte however the project can be developed to classify other blood cell subtypes which is not the primary focus of this project.

## Technologies Used
- Python

## Explanation of the data and data source
This dataset has been extracted from Kaggle sing the following url link https://www.kaggle.com/paultimothymooney/blood-cells/home The Motivation to classify this dataset is coming from the fact that the diagnosis of blood-based diseases often involves identifying and characterizing patient blood samples. Automated methods to detect and classify blood cell subtypes have important medical applications. This dataset contains 12,500 augmented images of blood cells (JPEG). There are approximately 3,000 images for each of 2 different cell types extracted grouped into 2 different folders (according to cell type). The cell types that were used are Eosinophil and Lymphocyte.
